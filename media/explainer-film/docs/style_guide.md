# Style guide

| | |
|---|---|
| Problem act (b0 to b40) | Night #0c0a09 ground with faint drifting Geist Mono DNS failures; paper type #fafaf9; muted #a8a29e eyebrows. UI on paper cards. |
| Turn (b40) | Paper floods the frame from the point where the two systems meet (circle wipe); the tree grows circle by circle. |
| Solution act (b40 to b84) | Paper #fafaf9 ground with the homepage's dot grid; ink type; white cards with the console's soft shadow. |
| Accent | None in the problem act. Green #16a34a appears only when a step finishes (the widget's checks, the "live" badge). |
| Errors | Inverted chips (ink on paper / paper on ink), never red text, per the brand page. |
| Display | Instrument Serif 96 to 196 px (1080p), tracking -0.015em, sentence case, the key phrase in italic. |
| UI | Inter 400/500/600; records in Geist Mono. The widget is built at its native 400 px and scaled by camera (×1.92 wide, ×2.3 tall). |
| Motion | Closed-form springs only; heavy for type and the lockup, default for cards and camera, snappy for chips, pops and presses. Words rise through masks. One morphing container for the widget. |
| Cuts | Hard cuts on bar lines (b8, b30, b46, b68, b76); one whip (b16), one circle wipe (b40), one slab wipe (b26). |
| Rhythm | Something new every 1 to 4 beats; the problem accelerates (errors at b17, 19, 21, 22.5, 24, 25, then a 16-chip flood), the solution lands one check per beat. |
