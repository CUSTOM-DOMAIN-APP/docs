Run the connect flow once with a made up domain. Nothing real changes, and no card
is asked for.

<Steps>

<Step>

### Open a test mode application

[Sign up](https://app.customdomain.ai/signup), then create a test mode
application or open the one your workspace has. A test mode application connects
names that end in `.test`. See [test mode](/docs/guides/test-mode).

</Step>

<Step>

### Connect a `.test` name

Open the widget from the console's **Widget** page, enter a name such as
`www.acme.test`, and follow it to **Live**.

</Step>

</Steps>

**Done when** a made up domain shows **Live**.

Next: [Mint tokens](/docs/quickstart/mint-tokens).
