**Setup type: Guided manual.** Namecheap's API is open only to some accounts and replaces the whole zone on each write, so by default you add the records in the Namecheap DNS panel yourself. The app shows the exact values and verifies them for you.

Namecheap connects via the guided-manual path by default: CustomDomain™ shows the exact records and you add them in Namecheap's Advanced DNS panel, then it verifies. Namecheap does have an API, but its shape makes copy-paste the safer default.

## What you'll need

- A domain whose DNS is managed at Namecheap.
- Access to your app's CustomDomain™ dashboard (it shows the exact target for your account).

## The records

CustomDomain™ gives you the authoritative records for **your** account in the dashboard, typically a `CNAME` (or apex `A`/`ALIAS`) pointing your domain at the edge. Use the values shown there; the shape is always the same, the target is per-account. There is no separate ownership TXT to add on this path: control is proven by the rail itself, or by the records appearing in your own authoritative DNS. See [Setup types](/docs/concepts/ownership-and-setup-types#control-is-proven-by-the-rail).

## Setting it up on Namecheap

1. Open your Namecheap DNS panel ([here](https://ap.www.namecheap.com/domains/list/)).
2. Add the exact records the dashboard shows, usually one `CNAME` (or `A` records if you are connecting the apex).
3. Come back; CustomDomain™ polls DNS and marks the domain live once records resolve.

## Namecheap specifics

- Namecheap's DNS API is a full-zone `setHosts` replace, it overwrites the whole record set rather than adding one record, and it is IP-allowlisted, so the guided-manual path is the default to avoid clobbering existing records.
- Add the records under Domain List > Manage > Advanced DNS.
- For accounts that qualify (20 or more domains, a $50 balance, or $50 spent in the last 2 years), an API key works too: switch API access on, whitelist `34.192.32.132`, and paste the key in the console's connect flow. The adapter reads the zone and writes it back with only our records changed. See [Provider setup](/docs/dns/provider-setup#namecheap).
- Domains on Namecheap **hosting** nameservers are edited in cPanel's Zone Editor instead.
- Sign-in through Namecheap's MCP server, which needs no API eligibility and no IP allowlist, is built but not switched on yet. It is switched on only after a live test passes, so it is not offered in the console or the widget today.

## How you know it worked

CustomDomain™ checks public DNS until every record resolves, then the dashboard shows the domain **live**. When the CustomDomain™ edge serves the domain (the Edge plan and up), it issues and renews the TLS certificate for you, so HTTPS works once the domain is live. Every live domain is then checked hourly against its records, so a later change at Namecheap shows up instead of breaking the domain unnoticed.

## FAQ

### Why isn't Namecheap one-click?

Namecheap's API replaces the entire DNS zone in one call and requires IP allowlisting, so a safe automatic write isn't practical for arbitrary users. The guided path shows you the exact records to add, which is quick and can't overwrite your other records.
