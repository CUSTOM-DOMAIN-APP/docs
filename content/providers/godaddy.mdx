# Connect a GoDaddy domain

**Setup type: Automatic (API token).** You paste a scoped GoDaddy API token once and the app writes the records for you; nothing to copy by hand.

GoDaddy connects with a scoped access token you generate once, and CustomDomain™ writes the records for you. GoDaddy speaks the Domain Connect standard, but it has not onboarded our one-click templates yet, so a token (or adding the records by hand) is the way in today.

## What you'll need

- A domain whose DNS is managed at GoDaddy.
- Access to your app's CustomDomain™ dashboard (it shows the exact target for your account).
- A scoped GoDaddy API token (see below).

## The records

CustomDomain™ gives you the authoritative records for **your** account in the dashboard, typically a `CNAME` (or apex `A`/`ALIAS`) pointing your domain at the edge. Use the values shown there; the shape is always the same, the target is per-account. There is no separate ownership TXT to add on this path: control is proven by the rail itself, or by the records appearing in your own authoritative DNS. See [Setup types](/docs/concepts/ownership-and-setup-types#control-is-proven-by-the-rail).

## Setting it up on GoDaddy

1. Create a Personal Access Token on GoDaddy's [Personal Access Token page](https://developer.godaddy.com/en/personal-access-token), with only `domains.domain:read` and `domains.dns:update` and a short expiration.
2. Paste it into the console's connect flow, under **API key**. (The widget doesn't take provider keys from your customers; it shows them the records to add by hand.)
3. CustomDomain™ writes the records for you and verifies them.

## GoDaddy specifics

- Use a Personal Access Token (a `gd_pat_...` key) from developer.godaddy.com. Any GoDaddy account that holds a domain can create one. Older key and secret pairs still work, but GoDaddy has deprecated them for the Domains API.
- One-click setup (Domain Connect) is waiting on GoDaddy to onboard our templates (none of our 18 served on 2026-09-28), and GoDaddy offers no sign-in to third parties.
- GoDaddy has no ALIAS or ANAME record, so a root domain needs A records; or connect `www` instead.

## How you know it worked

CustomDomain™ polls public DNS and issues the TLS certificate automatically. When the dashboard shows the domain **live**, HTTPS is serving. Drift monitoring then watches the records so a later change at the provider doesn't silently break the domain.

## FAQ

### Where do I get the GoDaddy token?

On developer.godaddy.com, create a Personal Access Token with only `domains.domain:read` and `domains.dns:update`. Paste it into the connect flow once; it's used only to add the records for the domain you're connecting.

### Can I avoid the token entirely?

Not with one click yet: GoDaddy has not onboarded our Domain Connect templates and offers no sign-in to third parties. You can add the records by hand in GoDaddy's DNS panel instead; the app shows them and verifies them.
