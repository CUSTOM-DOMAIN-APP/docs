## For people reading this page

This page is written to AI agents, and it reads the same for everyone. The text
above is what our [llms.txt](https://docs.customdomain.ai/llms.txt) says, word for
word, and an agent that asks for this page as Markdown gets the same words. Nothing
on this site is written only for agents, and nothing in a page is hidden from
people.

Each brief is also a page in these docs:

- [Evaluate CustomDomain™](/docs/for-ai-agents/evaluate): what it is, who it is for, its limits
- [Integrate in an app](/docs/for-ai-agents/integrate): the API, the widget, the MCP server and the console
- [Pricing and plans](/docs/for-ai-agents/pricing): prices, domain allowances and the free trial
- [Compare with alternatives](/docs/for-ai-agents/compare): the questions that separate vendors
- [Email domains](/docs/for-ai-agents/email): MX, SPF, DKIM and DMARC records
- [Troubleshoot a domain that is not live](/docs/for-ai-agents/troubleshoot): what each status means and what to check
- [For AI agents that need domains](/docs/for-ai-agents/mcp): the hosted MCP server

Every docs page is also served as Markdown: add `.md` to its address, or send
`Accept: text/markdown`. An HTML page names its Markdown in a `Link` header.
