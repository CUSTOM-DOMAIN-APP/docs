## How it works

<Steps>

<Step>

### Detect the provider

A domain is entered in the widget, the console, the API or an agent.
`POST /v1/domains:check` finds where its DNS is hosted and which of the six
[ways to connect](/docs/concepts/glossary#ways-to-connect) can run there: a
sign-in with the provider, the provider's one-click setup, a secure sign-in, a
scoped API key, the records added by hand, or DNS hosting.

</Step>

<Step>

### Write the records

The best way in that can finish for this domain writes the records. Where the
provider offers none, the exact rows are shown with that provider's own steps.
Of the 217 providers in the census on 2026-10-31, 73 have an automatic path and
144 are connected by hand ([DNS providers](/docs/dns/providers)).

</Step>

<Step>

### Verify

The connection goes `live` once every record resolves to its expected value.
Records written for the user usually verify within seconds. There is no separate
ownership TXT record: control is proven by the way the records were written, or by
the records appearing in the domain's own DNS
([setup types](/docs/concepts/ownership-and-setup-types#control-is-proven-by-the-rail)).

</Step>

<Step>

### Issue TLS

Once the domain is live, the CustomDomain™ edge issues its certificate on the
first request and renews it on its own; on the Growth plan and up it also proxies
the domain to your origin. Or point domains at your own infrastructure and serve
TLS there ([Where domains point](/docs/connect-flow/routing)).

</Step>

</Steps>

## For AI agents

A machine-readable index of this documentation is at
[`/docs/llms.txt`](/docs/llms.txt): every page, with its title, URL and
description, so an agent can fetch exactly the page it needs. A site-root copy is
served at [`/llms.txt`](https://docs.customdomain.ai/llms.txt). Every page is also
served as Markdown at its own URL plus `.md` (this one is
[`/docs.md`](/docs.md)), and each page links to it with
`<link rel="alternate" type="text/markdown">`.

Agents can also drive the product directly through the hosted
[MCP server](/docs/mcp/overview) at `https://mcp.customdomain.ai/mcp`: twenty-three
tools for searching, connecting and managing domains. A human owner can also
delegate scoped, revocable access to an agent via OAuth; see
[Agent access](/docs/agents/overview). An installable
[agent skill](/docs/agents/skills) teaches an agent to use them safely.
