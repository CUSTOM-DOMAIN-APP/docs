CustomDomain™ lets your users connect a domain they already own. It finds the DNS
provider, writes or shows the records, checks them and issues HTTPS.

Add it with a drop-in widget, the REST API or the MCP server. Or connect a domain
of your own in the console, with no code.

## How it works

<Steps>

<Step>

### Detect the provider

You enter a domain in the widget, the console, the API or an agent.
`POST /v1/domains:check` finds where its DNS is hosted and which
[ways to connect](/docs/concepts/glossary#ways-to-connect) can run there.
They are a sign-in with the provider, the provider's one-click setup, a secure
sign-in, a scoped API key, the records added by hand, or DNS hosting.

</Step>

<Step>

### Write the records

The best way in that can finish for this domain writes the records. Where the
provider offers none, you see the exact rows with that provider's own steps.
[DNS providers](/docs/dns/providers) shows how each provider connects.

</Step>

<Step>

### Check the records

The connection goes `live` once every record resolves to its expected value.
Records written for you usually check out within seconds. There is no separate
ownership TXT record. The way the records were written proves control, or the
records appearing in the domain's own DNS do
([setup types](/docs/concepts/ownership-and-setup-types#control-is-proven-by-the-rail)).

</Step>

<Step>

### Issue HTTPS

Once the domain is live, the CustomDomain™ edge issues its certificate on the
first request and renews it on its own. On the Growth plan and up it also proxies
the domain to your origin. You can also point domains at your own servers and
serve HTTPS there ([Where domains point](/docs/connect-flow/routing)).

</Step>

</Steps>

## For AI agents

A machine-readable index of these docs is at [`/docs/llms.txt`](/docs/llms.txt).
It lists every page with its title, URL and description, so an agent can fetch
exactly the page it needs. A copy is served at the site root,
[`/llms.txt`](https://docs.customdomain.ai/llms.txt). Every page is also served as
Markdown at its own URL plus `.md`. This one is [`/docs.md`](/docs.md), and each
page links to its copy with `<link rel="alternate" type="text/markdown">`.

Agents can also drive the product through the hosted
[MCP server](/docs/mcp/overview) at `https://mcp.customdomain.ai/mcp`. A person can
give an agent scoped access they can revoke, through OAuth
([Agent access](/docs/agents/overview)). An installable
[agent skill](/docs/agents/skills) teaches an agent to use the tools safely.
