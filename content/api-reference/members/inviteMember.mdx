      - content: >-
          Creates a pending member and its single-use invite link. The response
          carries `invite_token`; send the invitee a link built from it. The
          link works for 7 days, after which the member is reported as `expired`
          until an admin resends or revokes it. The inviter's email is taken
          from the credential that sends the invite, never from the body.
          Requires admin or owner (`member:manage`); a caller cannot invite a
          role above their own, and `owner` is reached only by promoting an
          existing member.
