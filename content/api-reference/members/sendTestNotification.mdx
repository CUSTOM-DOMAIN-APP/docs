          Pushes one test notification to every browser in which
          `user_id` turned push notifications on. The console's server
          calls this behind its "Send a test notification" button,
          guarded by the provision secret exactly like `POST
          /members:email-changed`: the console has already checked the
          session and passes the signed in person's id, and the route
          takes no account, so a secret for one workspace cannot name
          another. The control plane holds the VAPID keys; without them
          it answers 503 `push_not_configured`. More than five tests a
          minute for one person answer 429 `rate_limited` with
          `Retry-After: 60`.
