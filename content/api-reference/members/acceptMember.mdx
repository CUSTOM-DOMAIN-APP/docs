      - content: >-
          Server to server: the console accepts an invite for a signed-in person
          whose email matches the invited one. An invite link alone accepts
          nothing: a call without the console's credential is refused with 403
          `invite_accept_requires_console`, and the invite stays usable. To join
          a workspace, open the invite link and sign in to the console with the
          invited email. The token is spent on success, once. A second accept that races the
          first, or one racing a resend that replaced the link, is refused with
          409. A repeat after the accept has finished finds no invite and
          answers 404, as does a link for an invite that was removed. A pending
          invite whose link has lapsed is refused with 410 `invite_expired`.
