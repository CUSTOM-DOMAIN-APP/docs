    contents:
      - content: >-
          Accepts the invite and returns the member with a member-scoped API key
          for the inviter's tenant. The token is the capability, so no API key
          is needed; when `email` is supplied it must match the invited email.
          The token is spent on success, once. A second accept that races the
          first, or one racing a resend that replaced the link, is refused with
          409. A repeat after the accept has finished finds no invite and
          answers 404, as does a link for an invite that was removed. A pending
          invite whose link has lapsed is refused with 410 `invite_expired`.
