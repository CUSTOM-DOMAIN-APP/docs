      - content: >-
          Sets the nameservers the domain had before the move back. With a key
          (sent once, or the migration's connected account) through the
          registrar's API (`rollback_path: api`); otherwise the old nameservers
          are handed to a person (`rollback_path: manual`, `next_step` names
          them). A migration that changed nothing at the registrar yet is simply
          stopped (`rollback_path: none`). The old DNS host's records were never
          touched, so the domain answers as before once the registry lists the
          old nameservers again. Idempotent. A widget token may move back but
          may not send a key. A delegated agent token needs `domains:connect`.
