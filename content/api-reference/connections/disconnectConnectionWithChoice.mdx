      - content: >-
          The same removal as `DELETE /connections/{id}` with a body. Send
          `credential` (a DNS provider API key) to authorize removing the
          records once when we did not keep the access that added them; it is
          used for this removal and never stored. The zone must show at least
          one of our records with that key, or the outcome lists the manual
          steps (the key may belong to another account). Answers `200` with the
          outcome; an end user's widget token must be bound as for `DELETE
          /connections/{id}`.


          A delegated agent token needs `domains:disconnect` and must send
          `confirm`, as for `DELETE /connections/{id}`.
