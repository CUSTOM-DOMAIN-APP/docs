          The single source of truth the widget renders, the OAuth callback
          writes, and the propagation poller verifies. Before records are
          applied, the default edge record is synthesized server-side.


          A delegated agent token needs `domains:read` or `domains:connect`.


          A widget token must be the connection's end user: a connection that
          names another end user than the token's `end_user_ref`, or names one
          while the token names none, answers `403` `token_wrong_end_user`
          before anything is read or changed, and a connection that names none
          is any token's. An API key, an app-scoped token and a delegated agent
          token are not limited by it.
