          Returns the caller's connection for a domain, for an app that stored
          the domain but not the connection id (for example to open the removal
          flow). A connect-scoped widget token must be minted for that domain,
          and finds a connection that names an end user only when minted with
          the same `end_user_ref`; an app-scoped token finds any domain of its
          application, and an API key any domain of its tenant.
