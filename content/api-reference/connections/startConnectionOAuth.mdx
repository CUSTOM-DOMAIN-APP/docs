          **Rail C (flagship).** Returns the URL the widget opens in a popup,
          bound to an HMAC-signed single-use `state`. The provider redirects
          back to `/v1/connect/oauth/callback`, which writes the connection's
          records with what the provider handed over. `flow` says which sign-in
          runs: `oauth2` (authorization code with PKCE S256),
          `vercel_integration` (the CustomDomain™ integration's install page;
          the user picks the Vercel team that owns the domain),
          `porkbun_handoff` (Porkbun's PKCE API key handoff: the user approves a
          key named after the domain; no client registration is needed) or
          `ovh_consent` (an OVHcloud consumer key limited to the domain's DNS
          zone, validated on OVHcloud's page for the chosen `region`). The
          credential is used for that write and dropped, unless the deployment
          keeps grants for this provider (`OAUTH_MANAGED_PROVIDERS` with
          `GRANT_ENCRYPTION_KEY`), in which case `managed` is true and it is
          stored encrypted for `:reapply`.
