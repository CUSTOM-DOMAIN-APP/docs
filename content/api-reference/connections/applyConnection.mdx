          **Rail B (API-token apply).** The scoped provider credential is used
          once to write the records and is never stored. The connection advances
          to `propagating`; the poller promotes it to `live` once the records
          appear in public DNS.


          A widget JWT applies to its own application's connections (a
          domain-bound token to its own domain only). An API key applies to a
          connection of any application in its tenant; a member's key needs a
          role that operates apps (not viewer).


          A widget token must be the connection's end user: a connection that
          names another end user than the token's `end_user_ref`, or names one
          while the token names none, answers `403` `token_wrong_end_user`
          before anything is read or changed, and a connection that names none
          is any token's. An API key, an app-scoped token and a delegated agent
          token are not limited by it.
