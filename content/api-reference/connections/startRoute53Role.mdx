          **Route 53 access role.** For a domain whose DNS is in Amazon Route
          53, the customer creates a limited IAM role in their own AWS account
          from the CustomDomain™ CloudFormation template instead of pasting an
          AWS access key. This call generates the connection's external ID
          (once: later calls return the same one), stores the hosted zone id
          when you pass one, and returns a CloudFormation quick-create link plus
          plain instructions. The role the link creates can be assumed by
          CustomDomain™ only with that external ID, can read only the chosen
          hosted zone, and can change only the records for the connected name.
          Idempotent. Answers `503` when this deployment has not set the rail
          up.
