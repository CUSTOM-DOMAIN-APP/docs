      - content: >-
          For whoever manages the account (`can_manage`, and never a viewer), it
          also carries `more_domains`: the domains the key lists at the provider
          that the workspace has not connected, to offer them with `POST
          /provider-accounts/{id}/connect`. Listing them is a use of the key, so
          it is asked of the provider on this read (kept for a minute) and left
          out for anyone else, for a key an end user's secure sign-in made, and
          for an account with no usable key. The read changes nothing: a key the
          provider refuses, or a list that fails, leaves `more_domains` out and
          the account as it was.
