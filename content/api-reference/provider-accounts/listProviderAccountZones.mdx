      - content: >-
          Lists the provider's domains with the kept key. `listed` is false for
          a provider that cannot list them. A refused key flags the account
          `needs_reconnect`. It takes an admin, an owner or the member who
          connected the account (`can_manage`), as connecting domains with it
          does; anyone else gets `403`. A one time account past its hour answers
          `409`, and its key is deleted then if the hourly cleanup has not
          deleted it yet. A key an end user's secure sign-in made in the widget
          answers `403`: it never lists the domains of the end user's account.
          The list is one read of the workspace's hourly budget of reach checks:
          once it is spent the call answers `429` `reach_quota` with `Retry-After`
          and asks the provider nothing.
