      - content: >-
          Creates a connection for each domain under the application and writes
          its records with the account's key (keeping the CAA and TXT values
          already there and recording what each write replaced). Each domain is
          linked to the account; a continuous account then keeps them in sync. A
          domain the application already serves is only linked. A one time
          account deletes its key once the domains are connected, even when the
          caller has gone away by then, and past its hour answers `409`. A
          domain in a zone the key does not reach fails alone
          (`zone_not_reached` on the connection); the account is flagged
          `needs_reconnect` only when the provider refuses the key itself, which
          is checked with a request that does not depend on the zone. Takes an
          admin, an owner or the member who connected the account.
