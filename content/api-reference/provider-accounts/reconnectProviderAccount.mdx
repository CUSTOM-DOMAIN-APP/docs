      - content: >-
          For an account the provider stopped accepting, or a one time account
          whose key was deleted. Everything is checked before anything is kept:
          the access mode, then the key (listing the provider's domains, or
          reading `check_domain`, a selected domain or a domain the account
          connected, for a provider that cannot list them), and for a `selected`
          account that the key reaches every selected domain. `params` sent with
          the key replace the kept ones. Takes an admin, an owner or the member
          who connected the account. A key made at a secure sign-in answers
          `409`: it is renewed by signing in again (the reconnect mode of the
          sign-in), not by pasting a key. `continuous` access (asked, or the
          account's own) for a credential that is used once and never kept
          answers `422` `use_once_credential`; send `access` `one_time`. The new
          key is recorded in the audit log (`provider_account.key_replaced`).
