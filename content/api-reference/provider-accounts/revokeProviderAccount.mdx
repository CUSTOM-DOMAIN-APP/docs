      - content: >-
          Deletes the key and the account. Its domains stay connected and served,
          without continuous access; each domain's timeline records it. The answer
          says what that leaves: `used_by` is how many domains used the account, and
          `revoke_url` is the provider's page where the key itself is deleted. It
          deletes CustomDomain™'s copy only, for a key a person pasted as for a
          lasting API key the cloud browser's agent made: the key lives at the
          provider until it is deleted there (no provider documents an API that
          revokes one), and the application receives `credential.removed` for a key
          the agent made. Anyone who operates applications may remove an account; a
          viewer may not (`403`).
