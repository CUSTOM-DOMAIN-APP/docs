          The origin the edge proxies to for any of this application's
          connections that have no origin of their own. Resolution order is: the
          connection's own origin, then this default, then none (the edge
          answers 421).


          This exists because a per-connection origin is the wrong grain for the
          common case: one application serving thousands of customer domains,
          all proxying to the same place and dispatching on `X-Forwarded-Host`.
