          performs the actual ACME issuance on first handshake and reports back.
          Optionally sets `secure_root_domain` so the edge also secures the
          registrable apex. A domain has one certificate row. Returns 409 when
          another application tracks that row, unless this connection is the one
          the edge serves and the row's application serves nothing for the
          domain, in which case this connection takes the row over.
