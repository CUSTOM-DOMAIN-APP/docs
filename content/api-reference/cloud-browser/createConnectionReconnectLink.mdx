      - content: >-
          For a connection whose records were written with a lasting API key the
          cloud browser's agent made at the DNS provider. The link opens the
          hosted connect page in reconnect mode, straight on the sign in for
          that provider: after the end user signs in, the agent makes a new key
          with the same scopes, checks it and swaps it in, and no DNS record
          changes. It is a shared flow link (`/connect/{token}`): it works once
          and expires after 14 days.


          With `send: true` and the end user's email address on the connection
          (and the end user email feature on), CustomDomain™ emails the link on
          the application's behalf and the answer is `emailed: true` with no
          `link`; otherwise the answer carries the `link` to pass on. The
          control plane also emails one by itself 30 and 7 days before the key's
          end and when the provider stops accepting it. A connection with no
          such key answers `409` `not_reconnectable`. A delegated agent token
          needs `domains:connect`.
