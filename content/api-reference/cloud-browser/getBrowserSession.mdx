          The session view. Every call is the popup's heartbeat: a session that
          is not polled for 90 seconds before approval is ended and its browser
          released. The response is `Cache-Control: no-store`, because the view
          can carry the live view address, which anyone holding can drive.


          Once the session has kept a lasting API key for the connection, the
          view carries `kept_key`: the key's `name`, the provider's `page` that
          deletes keys, its `rights` and when it ends (`expires_at`), so the
          last screen can say which key was kept and where to remove it. A key
          that was made and not kept is `left_key` instead.
