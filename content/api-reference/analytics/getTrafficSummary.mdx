          status class, and the bytes it relayed to visitors, as a series (one
          point per hour for `24h` and `7d`, per UTC day for `30d` and `90d`,
          every bucket present) with totals and the busiest domains. Only
          traffic that passes through the edge is counted: a domain whose
          records point at the integrator's own servers (connected for DNS only)
          never appears. Counts arrive from the edge once a minute. Hourly
          figures are kept 14 days, daily figures 400 days. API key; any member
          role; `app_id` narrows to one application of the key's tenant (another
          tenant's application is a 404).
