          Off on the hosted service. This route registers a domain without
          taking a payment, so it needs both `SELL_PURCHASE_ENABLED` and its own
          switch `SELL_DIRECT_PURCHASE_ENABLED`; buy through checkout instead. A
          required `Idempotency-Key` header (1 to 255 visible ASCII characters,
          kept for 24 hours) dedupes retries so a registration is never charged
          twice. The same key and body again answers the first result with the
          response header `Idempotency-Replayed: true`; the same key with
          another body answers `422` `idempotency_key_reused`; a key still
          running answers `409` `idempotency_in_progress` with `Retry-After`.


          A delegated agent token needs `domains:purchase`, plus the `quote_id`
          from `POST /registrar/purchase-quote` and the `confirm_code` the person
          received by email; the grant's monthly
          spend cap is charged first, and a purchase that would pass it answers
          `409`. A tenant API key is refused with `401`. A workspace that
          billing refuses answers `402`.
