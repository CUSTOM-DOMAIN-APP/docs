          One row for every try to send an event to an endpoint, newest first. A try that
          failed and will be tried again carries `next_attempt_at`.
          
          API key: all the tenant's apps. Widget JWT: the calling app. `?app_id=` narrows to
          one application; `?type=` filters by event type; `?endpoint_id=` and `?event_id=`
          narrow to one endpoint or one event. Page with `limit` (1 to 200, 50 when only
          `cursor` is sent) and `cursor` (the `next_cursor` of the previous answer) until
          `next_cursor` is absent. Sent with neither, it answers the newest 100 and no
          `next_cursor`. Rows are kept 30 days. A delegated agent token needs `app:read`.
