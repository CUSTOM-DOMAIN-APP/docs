          Deletes one of your applications together with what belongs only to
          it: its API keys stop working, and its webhook endpoints, share links
          and settings are removed. Needs an admin or owner key (it revokes
          keys). Another tenant's application is a 404.


          Refused with `409` when deleting would break something that works,
          each with the reason in `details`: `default_application` (your
          workspace's default application, the oldest one: the signup key and
          your team's access belong to it, so it also keeps your last
          application), `application_key_in_use` (the key making the request
          belongs to this application) and `application_has_domains` (it still
          has domains, in any state; disconnect them first with `DELETE
          /connections/{id}`).
