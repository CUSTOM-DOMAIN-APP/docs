    headings: []
    contents:
      - content: >-
          Send any of `name`, `nameserver_migration` and `end_user_saved_access`
          (at least one); everything is checked before anything is saved.


          `nameserver_migration` sets whether the application offers to move an
          end user's nameservers and where to (`{"mode": "off"}` clears it). A
          `dns_host` target names a connected provider account of the workspace
          with continuous access at a DNS host whose API creates zones; only
          this application's migrations ever use it.


          `end_user_saved_access` sets whether a returning end user may reuse
          the access their own secure sign-in kept (`true` is the default; see
          the `Application` schema). It takes `true` or `false`, never `null`.
          A test mode application keeps no saved access, so `true` is refused
          for it with `400`. Needs a key that may write the application (a
          viewer's key is a `403`).
