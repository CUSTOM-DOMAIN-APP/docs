      - content: >-
          Replaces the setting. `mode` is `default` (the CustomDomain™
          sender), `smtp` (the platform's own mail server, with the
          notice's From taken from `from_address` and `from_name`) or
          `none` (nothing is sent; use the `connection.records_outdated`
          webhook instead). With `smtp`, the host must be a public
          address, the port one of 25, 465, 587 or 2525, and TLS is
          always on: `implicit` on 465, `starttls` on the others. Plain
          text is not offered. The password is sealed at rest; leave
          `smtp_password` out to keep the stored one. A change of
          server, login or sender clears `verified_at`. A mail failure
          at send time falls back to the default sender for that message
          and is recorded in `last_error`. Requires `app:write`.
