    contents:
      - content: >-
          Send exactly one of `zone_file` (a BIND zone file, at most 256 KB) or
          `records` (at most 500). Records from a zone file are `imported`: for
          every name and type the file defines, they replace what discovery
          found. Listed records are `manual` and are added alongside what is
          there. Records CustomDomain™ needs for the connection always win: an
          imported record that collides with one is skipped with a note, and a
          listed one is refused with 409. Zone file lines that can't be hosted
          (SOA, the zone's own NS set, unsupported types, names outside the
          zone) are skipped, each with a warning naming its line. A zone holds
          at most 500 records.


          Once the zone is `active`, only an API key or an app-scoped widget
          token may change it; an end user's connect-scoped token may change the
          zone only during setup.
