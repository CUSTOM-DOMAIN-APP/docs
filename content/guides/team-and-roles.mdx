Your workspace can have as many people as you invite. Each person has one role.
Everyone can see the list of people. Owners and admins change it.

## Invite someone [#invite-someone]

1. Open **Team** in the console and choose **Invite**.
2. Enter their email address and pick a role.
3. Send. They get an email with a link to join.

An invite that is still waiting shows in the list. From there you can copy its
link, send it again or withdraw it. If an email is slow, send them the link
yourself.

## Who can do what [#who-can-do-what]

| | Viewer | Member | Admin | Owner |
| --- | :---: | :---: | :---: | :---: |
| See domains, analytics and the team | ✅ | ✅ | ✅ | ✅ |
| Change domains and applications | | ✅ | ✅ | ✅ |
| Create live API keys, webhooks and widget branding | | | ✅ | ✅ |
| Invite people and change roles | | | ✅ | ✅ |
| Billing and plan | | | ✅ | ✅ |
| Delete or hand over the workspace | | | | ✅ |

Only an owner can make someone an owner or change an owner's role. The last
owner cannot be removed. Anyone can leave a workspace they were invited to.

## Transfer the workspace [#transfer-the-workspace]

An owner can hand the workspace to another person who has already joined. Choose
**Transfer workspace** on their row and confirm. They become the owner and you
become an admin. If you do not see the button, the workspace does not offer it yet.

## When an invite does not work [#when-an-invite-does-not-work]

The invite page says which of these it is.

- **This invite has expired.** Ask an owner or admin to send a new one.
- **This invite was withdrawn.** The person who invited you took it back. Ask them to invite you again.
- **There's a newer invite.** Use the link in the most recent email.
- **This invite was already used.** Sign in with the account that accepted it.
- **Wrong email address.** Sign in with the address the invite was sent to.

If an invite never arrives, ask the sender to copy the link from **Team** and
send it to you directly.
